# Comparacion-de-BayesPrism-y-CIBERSORTx-para-la-deconvolucion-de-muestras-de-glioblastoma
Este repositorio contiene el código en R desarrollado para mi Trabajo de Fin de Grado, enfocado en la preparación y análisis de datos de deconvolución celular obtenidos de CIBERSORTx y BayesPrism. 

# Contiene:
* Script para preparar los datos de expresión génica del proyecto Ivy Glioblastoma Atlas Project (IvyGAP) y convertirlos a cuentas por millón (CPM) para su posterior deconvolución.

* Script para la preparación del archivo de referencia a partir de datos de expresión de célula única obtenidos del estudio de Couturier et al. (2020)

* Script para analizar los resultados de la deconvolución.

* Script para comparar los resultados de BayesPrism y CIBERSORTx

# Los datos utilizados provienen de:

* Ivy Glioblastoma Atlas Project (IvyGAP)

* Couturier et al., 2020: Single-cell RNA-seq reveals spatially distinct tumor microenvironments in glioblastoma.
